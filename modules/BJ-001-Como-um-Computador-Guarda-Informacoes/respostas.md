# Respostas

## Exercício 1

### Minha resposta

Porque o computador não entende a linguagem que escrevemos, é necessario que hava uma leitura, "tradução" para o que o programa seja realmente executado.

### Feedback

🟡 Parcialmente correto.

O principal motivo é que o SSD é muito mais lento que a RAM. O sistema operacional primeiro carrega o programa para a memória RAM e somente então a CPU começa sua execução. A tradução realizada pelo V8 acontece posteriormente.

## Exercício 2

### Minha resposta

Porque o código é salvo no disco rígido e permanece armazenado mesmo após desligar o computador.

### Feedback

🟢 Correto.

O armazenamento permanente é responsabilidade do SSD/HDD, enquanto a RAM é apenas uma área temporária de trabalho.

---

## Exercício 3

### Minha resposta

Porque os programas precisam ser carregados para a RAM para serem executados.

### Feedback

🟢 Correto.

Quando a RAM fica cheia, o sistema operacional utiliza memória virtual (swap), movendo dados para o SSD. Como o SSD é muito mais lento que a RAM, isso degrada significativamente a performance.
